# 手臂模拟器

一个运行在浏览器里的 3D 机械臂模拟与控制工具：加载 URDF 模型做实时渲染，用键盘、鼠标或关节角度输入控制 6 个关节，并能通过 Web Serial 直连真实舵机臂，实现仿真与实机同步动作。

- 维护者：HXR
- 项目仓库：<https://github.com/hxrzs/ArmRobot>

## 功能

- 加载 `public/URDF/genkiarm.urdf` 及配套 STL 网格，three.js 实时渲染（阴影、反射地面、轨道相机）
- 键盘控制 6 个关节，鼠标点击按键帽或 `+` / `-` 同样可以操作，按住持续转动
- 关节角度控制：6 组滑块 + 数字输入，前 5 个关节范围 -90°-90°，爪子 0°-90°，输入与仿真姿态实时联动
- 速度滑块统一调节每次转动的步长
- 通过 Web Serial 连接真实机械臂（Feetech SCS 舵机，ID 1–6），仿真与实机同步动作
- 实机安全限位：下发前按 URDF 限位换算步数并夹紧，超限时在页面上提示夹紧后的角度
- 通信队列指示：显示待执行指令数量，可一键清空积压的串口指令
- 首次加载资源较多（约 55 MB），页面会显示下载进度

## 快速开始

```bash
pnpm install
pnpm dev        # 开发调试
pnpm build      # 产出 dist/
pnpm preview    # 预览构建结果
```

连接实机请使用 Chrome / Edge 等支持 Web Serial 的浏览器，并通过 localhost 或 HTTPS 访问。

## 操作说明

### 键盘控制

| 关节 | 按键 |
| --- | --- |
| 腰部旋转 | `1` / `Q` |
| 大臂控制 | `2` / `W` |
| 小臂控制 | `3` / `E` |
| 腕部控制 | `4` / `R` |
| 腕部旋转 | `5` / `T` |
| 爪子控制 | `6` / `Y` |

同一行的两个键方向相反，按住即持续转动，松开停止。控制面板里的绿色 `+`、红色 `-` 和按键帽都可以直接用鼠标按住，效果与按键盘完全一致；顶部的速度滑块（0.1–1）决定单次转动的角度。

### 角度控制

「关节角度控制」区域为每个关节提供一组滑块和数字输入框，可直接输入目标角度并回车确认。爪子关节限位为 0°-90°，其余关节为 -90°-90°；超出 URDF 限位时数值会被夹紧到允许范围，并给出提示。

### 连接真实机械臂

点击「连接真实机械臂」，在浏览器弹窗中选择串口即可，波特率固定 1,000,000。

- 连接时会读取每个舵机的当前位置，作为角度映射基准，因此实机起始姿态不影响后续控制
- 已连接时，键盘与角度输入都会把目标位置换算成舵机步数下发，下发成功才更新仿真姿态
- 连接前请确认实机姿态与仿真基本一致，避免动作幅度过大造成损坏

## 目录结构

```
index.html                      页面结构、样式与控制面板
index.js                        场景初始化、URDF/STL 加载与渲染循环
robotControls.js                键盘/鼠标/角度控制、关节限位、Web Serial 舵机通信
public/URDF/                    机械臂模型与网格（genkiarm.urdf、meshes/*.stl）
public/3d-model/                备用 STL 网格（当前未接入）
feetech/                        Feetech SCS 舵机 SDK 与调试页面
feetech/pysdk/                  Feetech 官方 Python SDK 参考实现
vite.config.js                  构建配置
vercel.json                     静态托管配置
```

## 技术栈

three.js、urdf-loader、Vite；实机通信基于 Web Serial API 与 Feetech SCS 协议。

## 本版本主要改进

- 新增 6 组关节角度输入（滑块 + 数字框），支持爪子 0°-90°、其余关节 -90°-90° 的独立控制
- 新增实机安全限位：把 URDF 限位换算为舵机步数区间，下发前夹紧并在页面提示
- 新增通信队列指示与「清空队列」按钮，避免高频操作造成指令积压
- 修复连接初始化阶段扭矩 / 加速度 / 速度指令被跳过的问题
- 修复键盘控制中舵机位置取模导致的角度回绕问题
- 修复在输入框中打字会误触发关节动作的问题
- 统一实机与仿真的姿态映射，连接时记录步数与关节角基准
